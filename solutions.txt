PART 1: UNDERSTANDING WHAT IS HAPPENING
===========================================================

Meesho's system groups rows into "PRODUCTS" automatically.

HOW MEESHO GROUPS ROWS:
  When multiple rows in your upload have the same product name,
  Meesho treats them as VARIATIONS of ONE SINGLE PRODUCT.
  
  Example: You upload 5 rows, all named "Crystal Necklace"
  Meesho sees: 1 product with 5 SIZE VARIATIONS.
  
  Now Meesho enforces these rules for variations:
    - Name must be IDENTICAL across all size rows
    - Description must be IDENTICAL across all size rows
    - Images must be IDENTICAL across all size rows
    - Attributes must be IDENTICAL across all size rows
    - The 'variation' column must have a DIFFERENT value per row

  Since your generator creates UNIQUE descriptions/names for each
  row, Meesho sees them as variations with mismatching data → ERROR.


===========================================================
PART 2: THE ERRORS — EXPLAINED ONE BY ONE
===========================================================

ERROR 1: "Attributes/Product name/Description/Images cannot be
          different for the different sizes of the same product"
  CAUSE:  Multiple rows share a similar product identity but have
          different data. Meesho thinks they are size variations.
  
ERROR 2: "Same value added in the 'variation' column for this product"
  CAUSE:  All your rows have the same value (e.g., "Free Size") in
          the variation column. For a grouped product, each row MUST
          have a unique variation value.

ERROR 3: "Crystal(Warning), comfort(Warning), elegant(Warning)
          detected in PRODUCT NAME / DESCRIPTION"
  CAUSE:  These words are flagged as "Warning" keywords by Meesho.
          WARNING = allowed (not blocked). You can keep these.
          Only "Error" keywords will block the listing.
  ACTION: IGNORE these. Your listing will still go live.

ERROR 4: "Wrong/Defective Returns Price should be lower than
          Meesho Price"
  CAUSE:  The returns price field is set to same or higher than
          the selling price. Meesho requires returns price < selling price.


===========================================================
PART 3: THE ONE STRONG SOLUTION
===========================================================

SOLUTION: MAKE EVERY ROW A COMPLETELY INDEPENDENT PRODUCT
---------------------------------------------------------

Instead of letting Meesho group your rows as variations of one
product, force each row to be its own separate listing.

HOW TO DO THIS: Give each row a slightly different product name.
Even a tiny difference breaks the grouping.

Strategy A — NUMBER SUFFIX (simplest):
  Row 1: Crystal Necklace Set for Women
  Row 2: Crystal Necklace Set for Women I
  Row 3: Crystal Necklace Set for Women II
  Row 4: Crystal Necklace Set for Women III
  
  Meesho sees: 4 SEPARATE products. No variation rules apply.
  Each can have its own description, images, attributes.

Strategy B — ADJECTIVE PREFIX (better for SEO):
  Row 1: Traditional Crystal Necklace Set for Women
  Row 2: Stylish Crystal Necklace Set for Women
  Row 3: Elegant Crystal Necklace Set for Women
  Row 4: Handcrafted Crystal Necklace Set for Women
  Row 5: Designer Crystal Necklace Set for Women
  
  Each adjective = a fully independent listing.
  Different descriptions are now ALLOWED and expected.

Strategy C — VARIATION COLUMN TRICK (if name must stay same):
  Keep name identical. Keep description identical. Keep images identical.
  Only change the VARIATION column per row:
    Row 1: variation = "Type 1"
    Row 2: variation = "Type 2"
    Row 3: variation = "Type 3"
  
  BUT: This creates one product with 3 variations. Meesho shows
  the buyer all 3 as options. This may or may not be what you want.

RECOMMENDED = Strategy B (Adjective Prefix)
  - Most natural-looking listings
  - Each is truly independent
  - SEO-friendly (different search terms)
  - No variation rules apply

  Required change:  Must be unique if you ever want true variation grouping.

CHANGE 3 — Wrong/Defective Returns Price:
  Current behavior: Returns price = same as or higher than Meesho Price
  Required change:  Returns price must be = Meesho Price × 0.9 (10% less)
                    OR set it to a fixed amount lower than the price.

CHANGE 4 — Warning Keywords (Crystal, elegant, comfort):
  Required change:  NONE. Warning keywords are allowed. Keep them.
                    Only remove actual "Error" keywords if present.
